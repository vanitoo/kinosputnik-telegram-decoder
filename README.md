# 🛰 KINOSPUTNIK Telegram Telemetry Decoder

Декодер сообщений `SatNetworkDB`: **Telegram → AX.25 → CAN → короткая телеметрия → SQLite/CSV**.

Работает на Windows 10/11, Linux и macOS. Python 3.10 или новее. Локально, без сервера и без отдельного Telegram-бота.

## Что умеет

- Подключаться к группе `@SatNetworkDB` через пользовательскую Telegram-сессию (Telethon).
- Определять ID темы по ссылке на сообщение `https://t.me/SatNetworkDB/492030`, если это Telegram-группа с темами. Если у группы нет тем, читает весь чат, отбирая только сообщения `KINOSPUTNIK`.
- Обрабатывать последние N сообщений и слушать новые.
- Находить HEX-RAW и координаты/время/параметры пролёта.
- Разделять AX.25-заголовок (16 байт) и внутренние CAN-поля 0x0032011E/1F и 0x10320110..1D.
- Расшифровывать **полную короткую телеметрию**: бортовое время, режим, счётчик ошибок, запущенное приложение, uptime, температуру платы и контроллера, напряжение, ток, мощность, флаги валидности.
- Сохранять **все** полученные RAW и CAN-кадры, включая расширенную телеметрию, структура которой пока не опубликована в переданном документе.
- Сопоставлять соседние части расширенного маяка (72 + 37 = 109 байт) при совпадении станции и времени приёма с допуском до 2 секунд. Это **эвристика**, не проверка CRC: результат сохраняется как HEX без придумывания значений.
- Исключать дубли сообщений по `(source, message_id)` и экспортировать короткую телеметрию в CSV (точка с запятой и BOM для Excel).

## Быстрый старт в Windows (PowerShell)

Распакуйте архив и перейдите в каталог проекта.

```powershell
cd kinosputnik-telegram-decoder
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Если PowerShell блокирует запуск `.ps1`, можно обойтись без активации окружения:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py demo
```

### 1. Проверьте работу без Telegram

```powershell
python main.py demo
```

Пример результата из присланных RAW:

### 2. Настройте Telegram

1. Войдите на [my.telegram.org](https://my.telegram.org), откройте **API development tools** и получите `api_id` и `api_hash` для своего Telegram-аккаунта (это не токен бота).
2. Создайте `.env` из `.env.example`:

```powershell
Copy-Item .env.example .env
notepad .env
```

```dotenv
TG_API_ID=12345678
TG_API_HASH=ваш_api_hash
```

3. Убедитесь, что вы вступили в группу/имеете право читать её сообщения.

### 2.1. Прокси (если Telegram недоступен напрямую)

Модуль `proxy_manager.py` управляет списком прокси: health-check, ротация и возврат на приоритетный адрес. В `.env`:

```dotenv
# Несколько адресов через запятую / точку с запятой / перенос строки
TG_PROXY=socks5://user:pass@host:1080,http://backup:3128
TG_PROXY_MODE=failover
```

Режимы `TG_PROXY_MODE`: `off`, `single`, `sticky`, `failover` (по умолчанию), `random`, `rotate`. Поддерживаемые схемы: `socks5://`, `socks4://`, `http://`, `https://`. Перед подключением бот проверяет живость прокси через `https://api.telegram.org` и подключается через первый рабочий; при отказе — переключается на следующий.

### 3. Получите историю и включите мониторинг

```powershell
python main.py watch --history 1000
```

При первом запуске Telethon запросит номер телефона, одноразовый код Telegram и (при необходимости) пароль 2FA. Далее локально сохранится файл `telegram_session.session`, повторный вход обычно не потребуется.

Из коробки используется ссылка `https://t.me/SatNetworkDB/492030`: она нужна для определения темы, но **492030 это ID сообщения, а не обязательно ID темы**.

Дополнительные режимы:

```powershell
# Только импорт истории и завершение
python main.py watch --history 3000 --once

# Вручную задать ID темы (если автоматическое определение не сработало)
python main.py watch --topic 12345

# Смотреть все темы/сообщения группы, но обрабатывать только KINOSPUTNIK
python main.py watch --topic all

# Использовать другую ссылку на сообщение в нужной теме
python main.py watch --link "https://t.me/SatNetworkDB/492030"

# Экспорт CSV
python main.py export-csv
```

Если в группе несколько сотен тысяч сообщений, не запрашивайте сразу всю историю. Начните с `--history 1000`, увеличивая при необходимости.

### 4. Декодировать скопированный текст Telegram без авторизации

Сохраните скопированные сообщения в UTF-8 файл, например `sample.txt`, затем:

```powershell
python main.py import-file sample.txt
python main.py export-csv
```

## Что сохраняется

- `data/satellite.db` (SQLite)
  - `packets`: исходный RAW, координаты, время, станция, метаданные.
  - `can_frames`: CAN ID, длина, содержимое каждого фрейма.
  - `telemetry`: расшифрованная короткая телеметрия.
  - `extended_reassembled`: сопоставленные фрагменты расширенной телеметрии (HEX без расшифровки).
- `data/telemetry.csv`: экспортированные расшифрованные показания.

## Важные ограничения

1. Схема короткого маяка взята из документа `Прием маяка УКВ.docx`, предоставленного пользователем. В документе показаны ID семейства `0x31`; в сообщениях `KINOSPUTNIK` встречается `0x32`. Для короткой телеметрии структура согласуется с тестовыми данными и арифметикой ток × напряжение; официального подтверждения идентичности прошивок нет.
2. В коротком блоке первые **8 байт служебные**, следующие **40 байт** представляют `uhf_short_telemetry_s`. Поля мощности интерпретируются по спецификации как `power_raw × 10 мВт`.
3. Применяется временная эпоха **2000-01-01 12:00:00 UTC**. Она выведена по совпадению меток времени с реальными приёмами; в присланном документе эпоха не оговорена.
4. `error_counter` и `mode` выводятся численно. Без документации прошивки нельзя решить, означает ли конкретный код реальную неисправность.
5. Расширенный блок 109 байт сохраняется, но **не** переводится в названия физических датчиков без дополнительной карты протокола.
6. AX.25 FCS/CRC и контрольные суммы CAN-обёртки **не проверяются**, поскольку в исходных образцах отсутствует подтверждённое описание их вычисления.
7. Локальный тест подтверждает декодирование примеров из сообщения. Подключение к Telegram по учётным данным пользователя в этой среде не проводилось.
8. Не публикуйте `.env` и `.session`: там содержатся секреты и доступ к Telegram-сессии. Они исключены в `.gitignore`.

## Проверка тестов

Тесты проверяют два полных коротких пакета, один продолженный фрагмент, значения телеметрии, SQLite и восстановление 109 байт.
